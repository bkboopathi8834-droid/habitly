# Habitly — Habit Tracker

Habitly is a React-based habit-tracking application designed to help users build consistent habits and manage their daily routines through a simple, user-friendly interface.

## Features

* Add and manage habits.
* Organize habits by category and frequency.
* Filter habits by category and completion status.
* Sort habits for easier management.
* Mark habits as completed.
* Delete habits and undo deletion.
* Save habit data in the browser using localStorage.

## Tech Stack

* React
* Vite
* JavaScript
* CSS
* React Router
* Browser localStorage

## Design Choices

* **Colors:** A consistent color palette helps create a clear visual hierarchy and makes important actions easier to identify.
* **Typography:** Readable fonts improve clarity and make habit information easier to scan.
* **Spacing:** Consistent spacing between sections and elements reduces visual clutter and improves readability.
* **Layout:** A structured layout helps users find habit-management features without unnecessary navigation.
* **Feedback:** Completion indicators and undo functionality help users understand their actions and recover from accidental deletion.

## UX Problem Identified and Solved

Users may find it difficult to maintain habits when their tasks are disorganized or progress is hard to track.
Habitly brings habit management into one interface, allowing users to add, categorize, filter, and sort habits.
Completion indicators help users recognize which habits they have finished.
The undo option provides a way to recover from accidental deletions.
Together, these features make everyday habit management more organized and convenient.
